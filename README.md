# Sri Sidhi Vinaayagar Meditation Academy — BalaMaya

A premium spiritual services platform built with Next.js, focused on providing accessible meditation, mantra healing, and energy cleansing practices.

## 🌟 Project Overview

This platform serves as a digital gateway for students and seekers to explore spiritual therapies and book personalized sessions. The design follows a "Gold Standard" template characterized by premium typography (Outfit, Playfair Display), fluid responsive layouts, and a content-first approach.

## 🚀 Key Features

- **Dynamic Service Architecture**: Individual detail pages for various services like Mantra Healing, Auto-Writing, and Energy Cleansing.
- **Mobile-First Design**: Fully responsive components (Service Cards, Hero Sections, FAQ Accordions) optimized for seamless mobile browsing.
- **Bilingual Readiness**: Support for English and Tamil (ENG/TAM) through a global `LanguageContext`.
- **FAQ Ecosystem**: Deep, 16-item FAQ sets for standardized service pages to ensure user clarity and trust.
- **Premium Aesthetics**: Integrated glassmorphism header, curated color palettes (#FDF2B5, #4E4633), and smooth micro-animations.

## 🛠 Tech Stack

- **Framework**: Next.js 14+ (App Router)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Typography**: Google Fonts (Outfit, Playfair Display, Geist)
- **State Management**: React Context API (Language, Scroll)

## 📦 Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Development Server**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```

## 📐 Design Standards ("Gold Standard")

The project adheres to a strict set of design rules for service detail pages:
- **Hero Stacking**: Grid-based layouts that stack vertically on mobile.
- **Flexible Dimensions**: Use of `w-full`, `max-w-X`, and `h-auto` instead of fixed pixel widths.
- **Typography**: Strict hierarchy using Outfit for body text and Playfair Display for accents.
- **Bilingual Consistency**: Conditional rendering of localized strings for all UI components.

## 🌐 Deployment

The platform is optimized for deployment on Vercel or any modern edge hosting provider. Ensure all environmental variables (if any) are configured in the dashboard.
